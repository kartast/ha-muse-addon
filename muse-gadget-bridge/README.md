# Muse Gadget Bridge

Make this Home Assistant a Muse device. Pairs with the Muse app over
Bluetooth (Muse Gadgets Linux Device SDK), then gives Muse full sight and
control of the house — every entity, every service — with an audit log line
for every service call it makes.

Set your SDK token from gadgets.muse.ai in the configuration, start the
add-on, and pair from your phone within the 10-minute window (see the
Documentation tab). Experimental, local build.
